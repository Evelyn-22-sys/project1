영어 지문 분석실

영어 지문을 직접 입력하거나 사진을 올린 뒤 제출하세요.

사용 순서
  1. 이메일과 비밀번호로 로그인합니다. 처음이면 회원가입을 먼저 하세요.
  2. 위쪽 사진 영역에 파일을 올리거나 촬영하면 한글과 영어가 아래 칸에 채워집니다. 틀린 글자는 그 칸에서 고칩니다.
  3. 제출을 누르면 해석, 요약, 해설, 변형 문제가 열립니다.
  4. 원하는 분석을 고른 뒤 다시 제출합니다. 변형 문제는 정답을 나중에 여세요.

파일을 더블클릭해 열면 브라우저가 API 응답을 막을 수 있습니다. 이 폴더에서 python3 server.py 를 실행한 뒤 http://localhost:8000 으로 여세요.

사진 촬영 / 파일 업로드

파일을 올리거나 촬영하면 이 브라우저가 한글과 영어를 읽어 아래 칸에 넣습니다.

영어 지문 사진 JPG · PNG · WEBP. 이 영역으로 파일을 끌어다 놓으세요.

카메라 시작을 누르면 웹캠 또는 휴대폰 카메라 화면이 여기 나타납니다. 지문이 선명하게 보이도록 맞춘 뒤 사진 촬영을 누르세요.

또는

아직 지문이 없습니다

지문이 깁니다. 호출 비용과 대기 시간이 늘 수 있으니, 필요한 문단만 남겨 보세요.

텍스트와 사진이 함께 있습니다. 분석은 입력한 텍스트를 기준으로 합니다. 사진만 분석하려면 텍스트를 지우세요.

분석 종류

하나를 고른 뒤, 아래 제출 버튼으로 요청을 보냅니다.

지문을 넣은 뒤 제출하면 해석, 요약, 해설, 변형 문제가 열립니다.

READY

분석 결과

생성된 해설과 문제는 초고입니다. 제출 전에는 지문과 대조해 확인하세요.

Folio는 전북대학교 영어영문학과 과제를 위한 프로토타입입니다. 분석 제출을 누를 때만 저장된 키가 선택한 서비스로 전송됩니다.

CONNECTION

API 설정

이 화면은 일반 메뉴에 없습니다. 저장한 키는 이 브라우저의 localStorage에 남아 다음에도 유지되고, 분석 제출을 누를 때만 전송됩니다. 공용 컴퓨터에서는 끝난 뒤 키를 지우세요.

서비스

발급: 키 만들기 페이지

사진 분석을 쓰려면 이미지를 읽는 모델이어야 합니다. 목록에 있는 모델은 이미지를 받을 수 있습니다.

OpenAI 주소가 다를 때만

기본 주소를 그대로 두세요. 주소를 바꾸면 API 키도 그 서버로 갑니다.

키를 저장하면 이 브라우저를 닫았다가 다시 열어도 유지됩니다. 호출마다 계정의 크레딧이 사용됩니다.
